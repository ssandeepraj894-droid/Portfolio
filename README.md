## 🌐 Deploying to GitHub as `sandeepraj/portfolio` (100% Free)

To have your portfolio live on the internet under the name **`sandeepraj/portfolio`**:

1. **Create a GitHub repository** named `portfolio` on your GitHub account (`github.com/ssandeepraj894-droid/portfolio`).
2. **Push your code**:
   ```bash
   git init
   git add .
   git commit -m "feat: unique portfolio for C. Sandeepraj"
   git branch -M main
   git remote add origin https://github.com/ssandeepraj894-droid/portfolio.git
   git push -u origin main
   ```
3. **Enable GitHub Pages**:
   - Go to your repository on GitHub.
   - Click **Settings** > **Pages**.
   - Under *Build and deployment*, set **Source** to `Deploy from a branch`, choose branch `main`, and folder `/ (root)`.
   - Click **Save**.
4. **Your live link is instantly live**:
   - 🌟 `https://ssandeepraj894-droid.github.io/portfolio/`
